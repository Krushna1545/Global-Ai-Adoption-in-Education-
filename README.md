# Global AI Adoption In Education: A Comprehensive Analysis

An interactive data analytics capstone project exploring global trends, regional disparities, and key factors driving artificial intelligence adoption within the educational sector.

## 📊 Project Overview
This project investigates how educational institutions worldwide are integrating AI technologies. Using Tableau, the dashboard highlights adoption rates, infrastructural readiness, and comparative metrics across different regions and educational levels.

## 🛠️ Tech Stack & Tools
* **Data Preparation & Analysis:** Excel / Python (Pandas)
* **Data Visualization & Dashboarding:** Tableau Public
* **Version Control:** Git & GitHub

## 📈 Key Insights / Dashboard Features
* **Global Adoption Map:** Geospatial view illustrating regional adoption density and readiness scores.
* **Comparative Bar Charts:** Breakdown of AI integration levels across primary, secondary, and higher education.
* **Trend Analysis:** Growth trajectory of educational AI tools over recent years.
